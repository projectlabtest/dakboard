LHC EVENTS BOARD CONTROL

Everything shown on the TV display is changed here. After Save, all TV outputs refresh automatically within about 2 seconds.

Change password

Hindi na ginagamit ang password na inilagay sa run-dakboard.bat kapag may naitang password na. Kung na-lock out ka, burahin ang admin-credential.json sa DAKboard folder at i-restart para magamit muli ang startup password.

Editor access

Ikaw ang magse-set ng editor username at password, at puwede mong i-reset ang password dito anumang oras. I-share ang link, username, at password sa staff para makapag-edit sila ng TV content. Hindi nila makikita ang calendar link at hindi nila mapapalitan ang admin password.
